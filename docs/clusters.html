Cluster glossary

What each Zigbee cluster actually does, and what it means for a device to declare it as Input or Output.

← Back to device explorer Find the right device Database on GitHub

Every device on this site declares, per Zigbee cluster, whether it's Input, Output, or both — and that distinction decides what the device can actually do for a specific job.

Input means the device can be commanded with that cluster — by Home Assistant, or by another Zigbee device bound directly to it — or reports data over it. It cannot use that cluster to control anything else itself.

Output means the device can itself send that cluster's commands directly to another device, over a Zigbee bind, without a hub involved. This is what makes a device a genuine controller for that function — e.g. a wall switch or remote that can operate a separate light or relay on its own.

Most switches and dimmers — even ones with a physical button — are Input only: the button operates the device's own load, it doesn't send Zigbee commands to anything else. Declaring Output for a cluster is the much rarer, more specific fact that actually answers "can I use this to directly control a separate device."
