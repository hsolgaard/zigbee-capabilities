Contribute a scan

This database only grows through real scans shared by real Home Assistant/ZHA users — there's no other way to add data to it.

The easiest way to contribute is the ZHA Bindings Manager Lovelace card: open a device's exploded view, select Check supported commands, then Share this scan. The card prepares a pre-filled GitHub issue for you to review and submit under your own GitHub account — nothing is sent automatically, and the shared record never includes your IEEE address, entity IDs, Home Assistant areas, or binding data.

Prefer not to use the card? See the database repo's own README for the raw submission format and schema.

Data is community-submitted and openly licensed — see the zigbee-capabilities repository for the full dataset, schema, and license.

Coverage is limited to devices someone has scanned and shared. A missing or empty result means nobody has confirmed it yet, not that a device is incapable of something.
